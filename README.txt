ADRXIOSMOD TÀI XỈU ANALYZER — WEB DEMO

Tệp chính: index.html
Trang quản trị: admin.html

Đăng ký/đăng nhập (demo): đăng ký tài khoản sẽ ở trạng thái chờ duyệt. Admin mở admin.html, nhập mật khẩu demo hiện tại: haimodvip, rồi bấm Duyệt/Chặn/Xóa.

LƯU Ý QUAN TRỌNG: Phiên bản này dùng localStorage nên trang index.html và admin.html chỉ chia sẻ danh sách tài khoản khi mở trên cùng trình duyệt và cùng origin (ví dụ cùng một website GitHub Pages). Không phải hệ thống xác thực an toàn; mật khẩu lưu cục bộ dạng văn bản và mật khẩu admin nằm trong mã nguồn. Không dùng cho tài khoản thật/dữ liệu nhạy cảm. Muốn quản lý nhiều người dùng từ nhiều thiết bị cần backend/database và xác thực phía máy chủ.

Tải toàn bộ index.html, admin.html và thư mục assets lên cùng thư mục trong GitHub Pages.

Bảng phân tích chỉ là demo heuristic; không tự lấy kết quả trực tiếp và không đảm bảo dự đoán chính xác.
