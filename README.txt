ADRXIOSMOD GAMEPRO WEB DEMO + ADMIN
- index.html: website demo.
- admin.html: trang admin.
- Mật khẩu admin demo: haimodvip
- Mở index.html, tạo tài khoản trên cùng trình duyệt, sau đó mở admin.html để duyệt/chặn/xóa.

LƯU Ý QUAN TRỌNG:
Đây là web tĩnh. Tài khoản và trạng thái duyệt được lưu trong localStorage; mật khẩu admin nằm trong JavaScript nên có thể bị xem/sửa. Không dùng để bảo vệ tài khoản thật trên website công khai. Muốn admin an toàn, cần backend, cơ sở dữ liệu và xác thực phía máy chủ.
Kết quả Tài/Xỉu chỉ ngẫu nhiên để minh họa, không dự đoán kết quả thật.


BAN TOI UU HIEU NANG:
- Da nen toi uu cac anh de giam dung luong tai tren dien thoai.
- Anh game duoc lazy-load.
- Sua nut dang xuat de quay ve man hinh dang nhap va an nut du doan noi.
- Neu website van cham sau khi deploy, hay thu hard refresh/xoa cache trinh duyet; toc do GitHub Pages va mang internet cung anh huong.
